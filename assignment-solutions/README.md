# ✅ Assignment Solutions – Recursion Module

This folder contains **model solutions** for the Recursion assignments
in the Java Data Structures Lab.

📌 Solutions were released **after the semester ended** for revision and self-study.

---

## 📚 Problems Covered

1️⃣ Count occurrences of a value in an array  
2️⃣ Insert an element at the end of a Singly Linked List  
3️⃣ Count even values in a Doubly Linked List  
4️⃣ Check if a Singly Linked List is sorted  

All solutions are implemented using **recursion only**, as required.

---

## 🎯 Learning Objectives

- Identify correct base cases
- Understand recursive decomposition
- Trace recursion stack behavior
- Apply recursion to arrays and linked lists

---

## ⚠️ Important Notes

- No iterative solutions are used
- Some problems assume Integer-based lists (clearly stated)
- Students should trace each function call manually
